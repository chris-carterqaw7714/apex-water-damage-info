## Getting Started

First, copy the repository to your local machine:

```bash
git clone https://github.com/chris-carterqaw7714/apex-water-damage-info.git
cd REPO
```

As a static HTML project, the site can be viewed by opening its main HTML file in a browser. A local static server is recommended for development and preview. For example:

```bash
python3 -m http.server 8000
```

After starting the server, open `http://localhost:8000/`.
